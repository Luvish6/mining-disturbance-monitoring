# Phase 22B preregistration — 2019 Indian static mining footprints

The target is visible mining-related surface footprint in a single historical season. The candidate inventory includes pits, waste, tailings, ponds and mining infrastructure. Boundaries, context and uncertain surfaces stay unlabeled pending review. This experiment is separate from the frozen Meghalaya temporal experiment.

## Observations and grid

Use 2019-01-01 inclusive through 2019-04-01 exclusive UTC for both sensors. The 2019 Maus mosaic does not supply polygon-level capture dates. Review requires an independent image within the pilot season or dated evidence bounding unchanged footprint through the season, with explicit supporting dates and scene IDs. Persist the source scene IDs and dates for model inputs separately.

Use north-up local UTM, 30 m cells, 64 × 64 patches snapped to the UTM 30 m lattice. The ordered float32 features are S2 B3 green, B4 red, B8 NIR (native 10 m, harmonized L2A stored values divided by 10,000), S1 VV and VH (GEE GRD IW dB), with optional SRTM elevation in metres as a separately documented extension. Do not infer native resolution from output spacing. Use per-band median on a shared optical scene mask with S2 cloud probability below 40, scene cloud at most 80, SCL 4/5/6, and B8A/B9 edge checks. Use descending radar, choose the relative orbit by greatest scene count then smallest orbit number, and reuse linear-power 20 m smoothing and the dB composite. Require two optical and two SAR observations per fused cell and at least 70% common valid coverage per usable patch. Record observation counts and exclude NoData. Use Earth Engine default nearest-neighbor grid sampling for export.

## Geometry and review

Build connected components across all candidate polygons at 2 km edge distance on an India-centred metric projection. Use a conservative 2.05 km projected search cutoff to allow for regional projection scale. Group membership is geographic and does not identify mine complexes. Assign Odisha to validation, Jharkhand to sealed TEST and other single-state groups to TRAIN. Exclude groups with multiple state assignments or intersecting multiple state polygons. Verify review/search windows against opposing groups using buffered distance and discard conflicts. Add any independently identified shared mine complex to a single partition or exclude it before admission. Leave the source and freeze hash in the local manifest.

Select up to 24 distinct safe development groups, eight validation and sixteen TRAIN, round-robin across available states, with a seed-42 hash as tie-breaker. Each sheet requests interior and boundary review and a separately identified hard-negative search in the same window, including non-mining bare terrain, construction or other confounders. An empty area outside Maus polygons is UNKNOWN. Admit only conservative georeferenced interiors, with both independent reviewers agreeing or documented adjudication, documented rights, suitable observation dates, ≥70% valid window support and documented relative positioning suitable at ≤30 m. Exclude ambiguous edges. Keep both classes in multiple independent TRAIN and validation groups before fitting. TEST reference evidence can only be assembled by a blinded custodian and remains sealed until design, checkpoints and thresholds are frozen.

## Models and evaluation

Prespecify seeds 42, 73 and 101 for later repetitions on the same split. Compare the existing 100-tree RF configuration (depth 16, minimum leaf 2, balanced class weights, one thread, up to 100,000 unique TRAIN cells with class-aware equal-group caps) and a single-date U-Net with width 16, Adam 0.001, batch one and up to five CPU epochs using masked BCE. Select checkpoint on validation loss. Cap combined pilot fitting at 30 minutes per controlled run. Fit per-band mean and population standard deviation from finite valid TRAIN features only, using divisor one for constant bands. Evaluate identical eligible cells. Report pooled and per-group precision, recall, F1, IoU, FPR and raw confusion counts. Undefined denominators are null. Report object detection rate as the fraction of independently reviewed positive objects matched one-to-one to 8-connected predictions at IoU ≥0.25, maximizing match count, with the reviewed support as the comparison domain. Use validation alone to select cutoff from 0.25, 0.50 and 0.75 by pooled F1 and then higher cutoff for ties. If three controlled recovery runs all have validation F1 below 0.30, stop and diagnose. Run only one final untouched TEST evaluation after the freeze.

QA is capped at two development patches (one TRAIN and one validation), 8,192 total cells. Seven diagnostic/feature bands use 229,376 raw float32 bytes before TIFF overhead (262,144 with DEM). Limit to two direct downloads, each ≤2 MiB, and no district export. A one-batch overfit diagnostic is reserved for admitted TRAIN data. No fitting is authorized in Phase 22B.
