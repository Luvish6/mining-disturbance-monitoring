Use the identical eight Phase 22E-R TRAIN patches in their original order. The Phase 22E-R network already uses GroupNorm, so BatchNorm running statistics cannot account for that rebound. No exhaustive search. Log ordered outcomes and every 25th checkpoint. Run exactly 1,000 optimizer updates per attempt, except nonfinite loss, nonfinite gradients/weights or the time cap. Every checkpoint from steps 900 through 1,000 inclusive must have pooled masked IoU ≥0.90 at threshold 0.50, and final mean masked BCE must be below 0.15. Repeat only the first seed-42 passing configuration with seeds 43 and 44. Stop U-Net work if either replication fails or if no initial configuration passes. Use deterministic CPU execution with two threads and an aggregate hard 720-second CPU budget and 720-second wall budget across all diagnostic attempts.

## Gated U-Net training

Only if all three diagnostics pass, train fresh seeds 42 and 43, 30 epochs maximum each. Keep the first passing architecture, GroupNorm, Adam learning rate, batch size and clipping. Fit on B3/B4/B8 normalized with frozen TRAIN statistics. Use masked BCE plus soft Dice with equal coefficients, valid known cells only, soft Dice smoothing 1. Select each seed's checkpoint by pooled validation IoU at 0.50, earliest epoch on a tie, patience five epochs without improvement. Select its operating threshold at the retained checkpoint using the RF threshold grid and F1 tie rule. Cap combined full-training CPU and wall time at 900 seconds each. Preserve completed results on failure. Do not retune or refit on validation.

Report seed variation and do not declare superiority when the difference is smaller than observed variation. Checkpoints remain local under the repository publication policy. Only code, configuration and sanitized metrics are publishable. No scale-up acquisition is authorized.
