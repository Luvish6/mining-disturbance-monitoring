## Smallest review handoff and next action

Send one acquisition request to CMPDI Geomatics and SECL using the three existing neutral Gevra search windows and a separate independently supported control window. Ask for native actual-work vectors or independent orthorectified imagery in both windows, with exact scene/survey IDs and capture dates, CRS, valid footprints and masks, independent positional error ≤30 m, and written rights for research and both reviewers. If working maps are supplied, require source observations or survey records and explicit excavation rather than administrative boundaries.

Reuse the two existing Phase 15E reviewer directories. Each gets the same neutral windows, admitted source material and a separate blank worksheet. Withhold the coordinator crosswalk, anomaly outlines, Sentinel model inputs and other reviewer's answers. Both reviewers map conservative interiors independently and may record UNKNOWN or REJECT. Check shared valid coverage and registration on the evidence, then use Phase 15B preflight and authoritative admission. A successful Gevra review would establish candidate references only. A separate frozen regional split and registered 14-band support, with both classes across sufficient independent blocks per split, remain necessary before fitting. Preserve all Meghalaya assignments.
