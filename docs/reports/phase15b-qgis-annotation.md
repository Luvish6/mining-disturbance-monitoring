# Phase 15B — QGIS annotation handoff

From the project root, run `python -B -m scripts.phase15b_annotation outputs/phase11c_india_discovery/inventory.json outputs/phase15b_annotation` to a new output directory. The existing Gevra feature receipt is separate. The visualizations at both sites use the cached Phase 11C optical composites, because their B8/B4/B3 channels and screening masks are available. Composite windows, actual contributing granule IDs and timestamps, cloud-screen settings, CRS and hashes are in each coordinator receipt. The source inventory does not report per-scene cloud fractions or independent positional error.

## QGIS steps

1. In a coordinator-only QGIS project, drag the two `coordinator/*_false_colour.tif` files and `coordinator/valid_masks.tif` onto the canvas. In raster **Properties → Symbology**, select **Multiband color**, red band 1 (B8), green band 2 (B4), blue band 3 (B3). Use identical display ranges across dates. In the mask raster choose **Singleband gray** and band 5 for common validity. The other bands contain the separate before/after SAR and optical masks.
2. For independent review, open a new QGIS project with independently acquired, licensed evidence only. Give each reviewer a separate copy of a neutral polygon layer in a GeoPackage, with the same neutral review ID and source packet. Withhold the coordinator composite, the other reviewer’s decisions, and the candidate category names. Each reviewer fills their own worksheet. If evidence is inadequate, record UNKNOWN or REJECT and leave the geometry empty.
3. After independent interpretation, drag `candidate_templates.gpkg` into the coordinator project, select the three WGS84 polygon layers, and use **Toggle Editing → Add Polygon Feature** to record conservative interiors by proposed category. Enter review and evidence IDs, retain UNKNOWN, and save edits. Keep the working package local. Export a selected polygon as EPSG:4326 GeoJSON for machine preflight.

## Preflight

Run the same module with the existing output directory plus `--site gevra --check-evidence <packet.json>` (or `--site bhubaneswari`). Supply `geometry`, `crs: EPSG:4326`, `decision` (the template layer name), and admission `reference_properties` with independent source URLs, positional error and its documented reference, and evidence group ID. The `before` and `after` objects need actual ISO capture date, scene/survey `id`, WGS84 `valid_footprint`, CRS, documented `rights_reference` and explicit coverage, reuse and independence attestations (`coverage_verified`, `reuse_permitted`, `independence_verified`). The two `reviews` each supply reviewer ID, `attests_independent`, `decision` and the same `packet_sha256`. Compute the packet digest with `src.phase3.annotation.sha` over the object containing geometry, before, after, decision and reference_properties. Match the final polygon and reviewed evidence before running the check.

This preflight detects mismatched dates, scene reuse, spatial suitability, incomplete coverage and rights declarations, and conflicting reviewer records. Human specialists verify the underlying records. Both sites remain UNKNOWN because independent seasonal evidence and a frozen regional boundary, spatial-block design and registered training coverage have not been supplied. Only the existing authoritative admission workflow can release labels. No training or new Earth Engine processing was performed.
