**No static or temporal model was fitted.** Accepted positive and negative counts are zero for train, validation and test in both proposed tasks. A defensible static pilot needs matching observation dates for independent mine and non-mine interiors, valid Sentinel support and geographical separation. Change additionally needs two dated observations with independent outlines showing new/expanded mining disturbance or verified no target change, licensed use, documented positional suitability and two independent decisions. No inference or metric was substituted.

Reproduce the local handoff from existing products:

```powershell
python -B -m scripts.phase15e_review outputs/phase15c_gevra/candidates/alerts.geojson outputs/phase15e_gevra_review
```

Send two separate reviewer directories with eligible independent evidence. Each includes three neutral WGS84 search windows and a blank worksheet. The 150 m padded boxes are locators for complete-window inspection. Keep the coordinator crosswalk and original anomaly outlines, scores and sensor changes private. For the next action, request independently dated actual-work vectors or orthorectified imagery covering all three windows and separate stable controls for both original seasons from CMPDI/SECL, including positional controls and written review-use terms. Run the Phase 15B preflight and existing admission process after both reviews.
