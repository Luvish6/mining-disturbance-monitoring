# Phase 6E — Supervisor briefing

**The project is ready to demonstrate real satellite preprocessing and observation-quality checks. Scientific validation of a mining classifier remains pending.**

- **What we measured.** We verified the two-district boundary and real Sentinel-1/Sentinel-2 seasonal inputs. The 500 m district coverage gate passed. The six bounded 30 m tiles contained 24,576 cells, all meeting common preprocessing support. Optical observation counts varied by location and season. These are sample-specific quality results.
- **What the maps show.** The real tile panels display changes in backscatter and optical indices between November–March seasons. Such changes can guide inspection. Their cause remains unverified.
- **What the models do.** Random Forest and Siamese U-Net pipelines run on synthetic software fixtures. The current Siamese baseline gives identical predictions if the two dates are swapped. No real classifier was fitted and no detection accuracy, model comparison or fusion benefit was established.
- **What independent evidence exists.** All 27 discovery leads remain UNKNOWN. Landsat contributes context, and historical high-resolution metadata yielded single-season leads only. The six feature tiles remain exploratory and unregistered. No split has either admitted class.
- **What the river pilot established.** Leshka was the only site with screened interior observations in both seasons. Five matched pairs yielded 12 common cells, below the 25-cell pilot floor. The spectral comparison was withheld, so the project makes no water-quality trend or downstream causal claim.

For the demonstration, use the local Phase 3G NDVI/support panels, the six-tile continuous change figure and the four-station date-support figure. Explain the denominators and keep the three conclusions distinct: sensor support was observed, model software was tested, and mining classification remains unvalidated.

The next scientific milestone is independently reviewed paired evidence with documented usage and positional error ≤30 m, followed by registered inputs and enough support for both classes across several independent blocks per frozen split. Planet imagery or IBM records can help fill these gaps if the original dated evidence meets the admission protocol.
