# Phase 9A — Real mining reference dataset feasibility

**Decision: NO-GO for real Random Forest fitting, Siamese U-Net training and held-out evaluation.** The accepted release contains **zero positive and zero negative polygons**. The train, validation and test partitions each have **zero blocks with admitted references**. The current evidence supports geographic routing, observation screening and targeted independent review. The target remains new or expanded mining-related surface disturbance between the frozen seasons, 2023-11-01–2024-03-31 and 2024-11-01–2025-03-31.

This audit reconciled the existing Phase 3 candidate and accepted-reference inventories, the Phase 6D local crosswalk and feature registration findings, and the Phase 7 evidence decisions with the later private KORPET diagnostics. It used saved evidence only. No imagery was fetched and no labels were generated. Source provenance and earlier archive decisions are retained in the [Phase 3B verification](phase3b-candidate-verification.md), [Phase 3D evidence inventory](phase3d-reference-evidence.md), [Phase 6D readiness audit](phase6d-reference-readiness.md) and [Day 3 source ledger](phase7-day3-reference-decision.md).

## Non-mining reference gaps

- **Historical field controls.** Um-Tyraa RR is a 2013 unmined-soil sampling locality. Lukha/Lunar SS3 is a 2013–2014 exposed riverbed/boulder locality. Both retain historical coordinate provenance only. Datum, local error, matched surface interiors, current study-window stability and independent reviews remain unresolved. Neither has an assigned block or a usable paired label. The 2019 global mining/control subset had zero local intersections. [Phase 3B background discovery](phase3b-candidate-verification.md)
- **Potential stable controls.** Forest, farmland and built surfaces need dated independent observation of the same conservative interior in both windows, consistent land use and adequate visibility. For agriculture, distinguish ordinary harvest and phenology from excavation. Historical mine surfaces require positive evidence of unchanged state over the pair.
- **Hard negatives.** Natural bare ground, riverbars, landslides, road cuts, construction and agricultural earthworks need both dated footprints and independent attribution, such as project drawings and dated work records or contemporaneous survey/field imagery. Distinguish mixed or unresolved causes and retain UNKNOWN. Historical land-cover maps can guide sourcing.
- **Phase 3E discovery cohort.** The local crosswalk retains 27 UNKNOWN leads across nine frozen blocks, three per split. Each block contributes one joint-change, one potential background and one alternative-disturbance lead. All have coarse two-window Landsat point context. Wayback metadata had five before-only and nine after-only leads, with no verified high-resolution pair. None overlaps the six sampled Phase 6B blocks. Screening ranks, thresholds, model outputs and partition membership stay out of interpretation packages. ## Minimum pilot and next experiment

1. **Plan for at least three contributing frozen blocks per class in each split after exclusions** as a practical pilot floor, distinct from the software minimum. That is 18 class–block slots. The same block may contribute both classes if each has independently verified support. Start with several conservative interiors per slot where evidence permits, across multiple sites and varied control types. Prefer additional independent blocks for any generalization claim. Pixels, repeated polygons and shared image footprints do not multiply independent block support.
2. **Prioritize evidence before feature acquisition.** Resolve reviewer-use rights and independent positional controls for the existing KORPET pair. Seek comparable actual-work plans or orthomosaics behind the Lumshnong inspections. For Sumon, require adequate dated coverage of its own interior and account for shared evidence with KORPET. Focus additional discovery on training blocks and hard negatives, then replenish weak validation/test strata. Register bounded features only after eligible interiors identify the required extents. Keep the existing partitions unchanged.
3. **Workload estimate, conditional on evidence availability.** Budget about 36 admitted polygon interiors as an initial planning target, two per class–block slot. Screen 50–75 candidate interiors to allow for rejection. At 15–30 minutes per initial screen, 20–40 minutes per independent verification and provenance/digitizing pass on the 36 retained candidates, and 5–10 hours for reconciliation and spatial QA, allow roughly **30–72 person-hours**. This assumes imagery, rights and controls are already available. Acquisition, field checks, approval delays and replacements for rejected blocks are additional. These are planning assumptions, not observed production rates.
4. **Next experiment: a blinded reference-admission pilot.** Use neutral IDs and independent dated sources only. For every proposed interior verify source lineage, usage rights, actual dates, interpretability, independent positional error ≤30 m and positive or negative attribution. Obtain and adjudicate a second independent review. Use a post-admission registered-feature dry run to tabulate common-valid pixels, exclusions, evidence groups and block support by class and split. Proceed to the prespecified RF ablations only after those gates pass. Reconsider U-Net after quantifying independent training patches and within-patch label support. No RF or U-Net fitting is authorized by this audit.
